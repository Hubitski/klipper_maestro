## Краткая шпаргалка по фактам

- Шина: `/dev/ttyS1`; DEST main 0x10 / head0 0x20 / head1 0x30 / bed 0x40.
- Пины головы: STEP PA7, DIR PC6, ENN PC7, TMC CS PA0, SPI PB5/6/7,
  heater PD7, thermistor PA4, fans PD4/PD5, HX711 DOUT PD3 / SCK PD6.
- Материнка: X PB2/PB1/!PD5, X1 PA2/!PA1, Y PC1/PC6, Z PB4/PA4,
  TMC CS PB0/PA3/PD6/PA0, `spi_bus: spi`, diag PD4, Z-endstop PC7 —
  фиктивная заглушка.
- Move queue: main 1024, bed 271, head0 **4 с [load_cell_probe]**
  (30 без него — HX711/trigger/sos_filter съедают ~286 Б кучи).
- Klipper-патчи: reset wait 250ms (fe55447); stepper_stop_on_trigger
  только при наличии шаговиков (f7df5b8); опрос trigger_analog каждые
  8 мс при хоуминге (2bbc6c0); host_power safety (7458ce9).
- Прошивочные фиксы: dynmem_end RAMEND (f2638db), гонка TXC, HX711
  без проверки лишних битов (eb0361b).
- `[host_power]`: pin 6, active_low False, startup_delay 1.5,
  off_when_shutdown True, off_on_disconnect False.
