## Краткая шпаргалка

- **Топология**: main `/dev/ttyS1` напрямую; периферия `/dev/ttyS0` через mux; PTY `/tmp/klipper_mcu_{head0,head1,bed}`; адреса 0x20/0x30/0x40.
- **Mux**: `host_multiplexer.py --periph-port /dev/ttyS0 --baud 250000 --bus-guard 0.001 --bus-timeout 0.020 --tap-log ~/printer_data/logs/maestro_bus.log`; poll 1 мс; hard 200 мс; 19 тестов OK; session_idle 15 с; quarantine 3/1 с delay.
- **Прошивки на платах**: head0 16368, head1 16366, bed 8848, main 44252. **Репо**: head 16416 FAIL (32 over), bed 8916, main 44252.
- **Причина PID `Timer too close`**: software PWM `heaters.py` (`pwm_time = read_time + report_time`), host-clamp +0.1; не ADC.
- **Причина load-cell hang**: 58 Б bulk + 17 Б status в 64 Б TX → `RetryAsyncCommand` 5 с; фикс 3-sample + host `samples_per_block=3`.
- **Причина bed `Timer too close`**: `command_query_analog_in` без clamp; фикс `7d62451`; bed 8916; головы не влезают.
- **Причина head0 lost**: bed timeouts → mux FIFO starvation; mux parser/ACK/quarantine фикс; теперь реальная ошибка bed.
- **Причина `Can not update MCU 'host'`**: рестарт `klipper-mcu.service` (stop klipper → restart klipper-mcu → start klipper).
- **Boot fans**: generic `CONFIG_INITIAL_PINS` ~44 Б не влезает; `toolhead_fans_init()` в `src/avr/main.c` (PD4 on, PD5 off), в прошитые головы пока не входит.
- **Bed**: сейчас один `bed_ts1` (PA4, 10 кОм); 4-датчиковый вариант — `sensor_list` полными именами `temperature_sensor bed_tsN`, `mean`, `maximum_deviation`; PA6 проверять.
- **Backups**: `~/printer_data/config/printer.cfg.bak-*` (bed4, bed4test, combinednames, loadcelltest, bed1, …).
- **Симуляция**: simavr (`atmega16`/`atmega32`, `avr-gdb`, USART→PTY, 3 инстанса + mux + Klipper) / simulavr / Microchip Studio / Proteus; QEMU/Renode ATmega16 нет.
- **Ключевые коммиты**: `7d62451` query-clamp (head build fail), `2c73c2b` mux session/quarantine, `8327cf7` mux parser/ACK/quarantine, `c9f3d52` report-only, `4ce94bf` fans init, `86a0d45` buffers/PWM host clamp, `24529cf` 3-sample, `0272c55` full clamp helper.
