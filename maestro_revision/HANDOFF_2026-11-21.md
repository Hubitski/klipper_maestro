## Краткая шпаргалка по фактам

- Шина: `/dev/ttyS1`, 250000; DEST main 0x10 / head0 0x20 / head1 0x30 /
  bed 0x40. Мультиплексор `klipper-multiplexer.service`, PTY
  `/tmp/klipper_mcu_*`.
- Головы: STEP PA7, DIR !PC6, ENN !PC7, TMC CS PA0, SPI PB5/6/7,
  heater PD7, термистор PA4 (EPCOS 100K B57560G104F), fans PD5/PD4,
  HX711 DOUT PD3 / SCK PD6.
- Материнка: X PB2/!PB1/!PD5 (CS PB0), X1 PA2/!PA1 (PA3), Y PC1/PC6 (PD6),
  Z PB4/PA4 (PA0), diag PD4, `spi_bus: spi`; Z-концевик PC7 — заглушка.
- Стол: heaters PD5/PD4/PD6/PD7 (зоны 1-4), термисторы PA4-PA7, подтяжка
  8.7к; `bed_ntc` 22°C/41k B3950; `pullup_resistor: 8700`.
- Прошивки: head0/head1 16322 Б (99.6%), bed 8812 Б (стек 160), main 45244 Б;
  move queue: main 1024, bed 29–38, **head0 4**, head1 30.
- Фьюзы: head0 lfuse 0xBF hfuse 0xC7; head1 lfuse 0x3F hfuse 0xD1
  (исправлен BOOTRST); lock 0xFF.
- host_power: `/etc/systemd/system/maestro-gpio6.service` (root oneshot,
  export gpio6, out/1, chown klipper), `M80` работает и в shutdown.
- Восстановление после аварии: stop klipper → restart klipper-mcu.service →
  gpio6=1 → start klipper.
- Ключевые фиксы: c6c9ee3 GPIO toggle; 38eea48/6c7de79/7f30679/2cf2c8e HX711;
  99bbea9 сброс устаревшей конфигурации MCU; 09b7983/26432ce/a0af827 ADC;
  d08ab71 стек стола; a5c111b M80 в shutdown + INITIAL_PINS.
